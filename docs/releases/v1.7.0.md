Panely for macOS 1.7.0 changes the translation engine. Apple Translation is replaced by Google's Gemma 4 E2B, which runs on your Mac's GPU. Gemma is the same model the Windows version uses. It reads each page's balloons together with the lines before them, so names and each speaker's speech level carry over. There's one model and no modes to choose. The separate speech-level step is no longer needed. Translated text also wraps better in narrow balloons, and the user guide covers drag-to-translate step by step.

## Download

Download **Panely-1.7.0.zip** below, unzip it and drag `Panely.app` to `/Applications`. The app isn't notarized. The first time you open it, right-click it and choose **Open**.

**Updating from 1.6.x**: replace the app. Your library, reading positions, bookmarks and balloon edits are kept. Books translated with 1.6.x are translated again the first time you open them, because translations from Apple Translation aren't reused. Your edits still apply to the new translations. To free the space the old translations take, use **Settings → Experimental → Clear Translation Cache**.

## Translation: one model, in context

- **Gemma 4 E2B translates every language pair.** It runs in the app with [llama.cpp](https://github.com/ggml-org/llama.cpp) on the GPU (Metal). Nothing you read leaves your Mac.
- **Lines are translated in context.** A page's balloons go to the model together, up to 16 at a time, along with the last few lines already translated. Names, who's speaking and each speaker's speech level carry over: casual lines stay casual and polite ones stay polite.
- **Balloons fill in as the model writes them.** On an M1 Pro a balloon takes about a quarter of a second, and a page a few seconds. In a 30-page test, 105 balloons were translated in about 23 seconds, starting with the model unloaded.
- **The model is downloaded once (3.35 GB).** Download it from the translation panel's big button, the banner over the page, or **Settings → Experimental → Translation Model**. The download shows a progress bar and can be cancelled. The file is checked against a pinned SHA-256 before it's used. Translations that were waiting for the model start by themselves when the download finishes. **Delete Translation Model…** in Settings frees the space; books already translated stay translated.
- **Memory**: about 3.5 GB while translating. The model is unloaded two minutes after the last balloon.

## Removed

- **Translation Mode (Fast / Accurate).** One model does everything.
- **Match Speech Level** and its need for Apple Intelligence. The model keeps speech levels itself.
- **Apple Translation language packs.** Packs you downloaded before can be removed in System Settings › General › Language & Region › Translation Languages.
- **The blue bar under the page slider.** It looked like a second slider. Translated pages are still marked in the thumbnail sidebar.

## Improved

- **Text in narrow balloons is easier to read.** A translation still prefers to keep words whole. But when keeping a long word whole would shrink all the text to less than 60% of the size the balloon allows, the word now wraps instead. A long Korean compound no longer makes the rest of a balloon tiny.
- **Japanese and Chinese with stray spaces** now wrap across the whole balloon. Before, the part after a space could be squeezed onto one line.

## Website and user guide

- The [download page](https://sejoung.github.io/Panely/) now covers both macOS and Windows, and links to each platform's repository and latest release.
- The user guide ([English](https://github.com/sejoung/Panely/blob/main/docs/manual.md) · [한국어](https://github.com/sejoung/Panely/blob/main/docs/manual.ko.md)) has a step-by-step guide to dragging over text the OCR missed, with new screenshots. It also covers moving between pages with thumbnails.
- The translation sections of the guide and README describe the new model.

## For developers

- llama.cpp's own prebuilt XCFramework is pinned by URL and checksum in `Packages/LlamaCpp`. The model (`TranslationModel`) is pinned to one revision, size and hash, the same file the Windows version uses.
- The sandbox now allows outgoing network connections (`com.apple.security.network.client`). They're used only to download the model.
- Translation jobs take a `BalloonTranslating` translator and a `PageAnalyzing` analyzer. The tests use stand-ins for both, so the batched, in-context job is tested without the model.
- `scripts/test-model.sh [--model PATH]` runs the tests that use the real model. `scripts/benchmark-translation.sh` also accepts `--model` and `--samples N`.
- `scripts/generate-snapshots.sh` can regenerate chosen manual images (`--list`, `--only`, `--output`).

## Known limitations

- Translation is experimental and makes mistakes, especially when OCR misreads the original. Quality hasn't been checked against a golden set.
- A speaker's speech level is usually kept, but not always. In testing, some polite Japanese lines came out casual in Korean (for example, 「彼女は眠いです」 → "그녀는 졸려").
- Needs macOS 26 or later. An Apple Silicon Mac is recommended; the app hasn't been tested on an Intel Mac, where translation is likely much slower.
- The first translation needs the 3.35 GB download.
- Translation jobs in progress stop when you quit (finished pages are kept).

## 한국어

Panely macOS 1.7.0은 번역 엔진을 바꿉니다. Apple 번역 대신 Google의 Gemma 4 E2B를 Mac의 GPU에서 실행합니다. Windows 버전과 같은 모델입니다. 한 페이지의 말풍선을 앞 대사와 함께 읽기 때문에 이름과 인물마다의 말투가 이어집니다. 모델은 하나이고 고를 방식이 없으며, 따로 말투를 맞추는 단계도 필요 없어졌습니다. 좁은 말풍선의 번역 글자도 더 보기 좋게 줄을 바꾸고, 사용 설명서에 드래그해서 번역하는 방법을 단계별로 넣었습니다.

### 내려받기

아래 **Panely-1.7.0.zip**을 내려받아 압축을 풀고 `Panely.app`을 `/Applications`로 옮깁니다. 공증(notarize)을 받지 않은 앱이라, 처음 열 때는 앱을 오른쪽 클릭한 뒤 **열기**를 고르세요.

**1.6.x에서 업데이트**: 앱만 바꾸면 됩니다. 라이브러리, 읽던 위치, 북마크, 말풍선 수정 내용은 그대로 남습니다. 1.6.x에서 번역한 책은 처음 열 때 다시 번역합니다. Apple 번역 결과는 다시 쓰지 않기 때문입니다. 고친 내용은 새 번역에도 그대로 적용됩니다. 예전 번역이 차지하던 공간은 **설정 → 실험적 기능 → 번역 캐시 지우기**로 비울 수 있습니다.

### 번역: 모델 하나, 문맥까지

- **Gemma 4 E2B가 모든 언어 조합을 번역합니다.** [llama.cpp](https://github.com/ggml-org/llama.cpp)로 앱 안에서 GPU(Metal)로 실행합니다. 읽는 내용은 Mac 밖으로 나가지 않습니다.
- **문맥과 함께 번역합니다.** 한 페이지의 말풍선을 최대 16개씩 묶어, 앞서 번역한 몇 줄과 함께 모델에 넘깁니다. 이름, 화자, 인물마다의 말투가 이어져, 반말은 반말로 존댓말은 존댓말로 남습니다.
- **모델이 쓰는 대로 말풍선이 채워집니다.** M1 Pro에서 말풍선 하나에 약 0.25초, 한 페이지에 몇 초 걸립니다. 30페이지 테스트에서는 모델이 내려가 있는 상태부터 말풍선 105개를 약 23초에 번역했습니다.
- **모델은 한 번만 내려받습니다(3.35GB).** 번역 패널의 큰 버튼, 페이지 위 안내 배너, **설정 → 실험적 기능 → 번역 모델**에서 받습니다. 받는 동안 진행 막대가 보이고 취소할 수 있습니다. 파일은 고정된 SHA-256으로 확인한 뒤에만 씁니다. 모델을 기다리던 번역은 다운로드가 끝나면 알아서 시작합니다. 설정의 **번역 모델 삭제…**로 공간을 비울 수 있고, 이미 번역한 책은 그대로 남습니다.
- **메모리**: 번역하는 동안 약 3.5GB를 씁니다. 마지막 말풍선을 번역하고 2분이 지나면 모델을 내려놓습니다.

### 없앤 것

- **번역 방식(빠르게 / 정확하게).** 모델 하나로 모두 처리합니다.
- **말투 맞추기**와 그에 필요했던 Apple Intelligence. 모델이 말투를 직접 유지합니다.
- **Apple 번역 언어팩.** 전에 받은 언어팩은 시스템 설정 › 일반 › 언어 및 지역 › 번역 언어에서 지울 수 있습니다.
- **페이지 슬라이더 아래 파란 막대.** 슬라이더가 하나 더 있는 것처럼 보였습니다. 번역된 페이지는 썸네일 사이드바에 계속 표시됩니다.

### 나아진 것

- **좁은 말풍선의 글자가 더 잘 읽힙니다.** 번역은 여전히 단어를 끊지 않는 쪽을 우선합니다. 다만 긴 단어를 통째로 지키느라 글자 전체가 말풍선이 허용하는 크기의 60%보다 작아지는 경우에는, 이제 그 단어를 줄바꿈합니다. 긴 한국어 복합어 하나 때문에 말풍선의 다른 글자가 모두 작아지지 않습니다.
- **띄어쓰기가 섞인 일본어·중국어**도 말풍선 전체 높이를 써서 줄을 바꿉니다. 전에는 띄어쓰기 뒤의 내용이 한 줄에 몰릴 수 있었습니다.

### 웹사이트와 사용 설명서

- [다운로드 페이지](https://sejoung.github.io/Panely/)에서 macOS와 Windows를 함께 안내하고, 플랫폼별 저장소와 최신 릴리스로 연결합니다.
- 사용 설명서([한국어](https://github.com/sejoung/Panely/blob/main/docs/manual.ko.md) · [English](https://github.com/sejoung/Panely/blob/main/docs/manual.md))에 OCR이 놓친 글자를 드래그해서 번역하는 방법을 새 스크린샷과 함께 단계별로 넣었습니다. 썸네일로 페이지를 옮기는 방법도 다룹니다.
- 설명서와 README의 번역 부분을 새 모델 기준으로 고쳤습니다.

### 개발자용

- llama.cpp가 직접 배포하는 XCFramework를 `Packages/LlamaCpp`에 URL과 체크섬으로 고정했습니다. 모델(`TranslationModel`)은 revision, 크기, 해시를 고정했으며 Windows 버전과 같은 파일입니다.
- 샌드박스에서 외부로 나가는 연결(`com.apple.security.network.client`)을 허용합니다. 모델을 내려받을 때만 씁니다.
- 번역 작업은 `BalloonTranslating` 번역기와 `PageAnalyzing` 분석기를 받습니다. 테스트에서는 둘 다 대역을 쓰므로, 모델 없이도 묶음·문맥 번역 작업을 검증합니다.
- `scripts/test-model.sh [--model PATH]`로 실제 모델을 쓰는 테스트를 돌립니다. `scripts/benchmark-translation.sh`도 `--model`과 `--samples N`을 받습니다.
- `scripts/generate-snapshots.sh`로 설명서 이미지를 골라서 다시 만들 수 있습니다(`--list`, `--only`, `--output`).

### 알려진 제약

- 번역은 실험 기능이라 틀릴 때가 있고, 특히 OCR이 원문을 잘못 읽으면 번역도 틀립니다. 골든 세트로 품질을 검수하지 않았습니다.
- 인물의 말투는 대부분 유지되지만 항상 그렇지는 않습니다. 테스트에서 일본어 존댓말 몇 줄이 한국어 반말로 나왔습니다(예: 「彼女は眠いです」 → "그녀는 졸려").
- macOS 26 이상이 필요합니다. Apple Silicon Mac을 권장합니다. Intel Mac에서는 테스트하지 않았고, 번역이 훨씬 느릴 것으로 예상합니다.
- 처음 번역할 때 3.35GB를 내려받아야 합니다.
- 진행 중인 번역 작업은 앱을 종료하면 멈춥니다(완료한 페이지는 남습니다).
